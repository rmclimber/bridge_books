# Project Guide

## Governing guidance

This book follows:

1. `../../CHARTER.md` for Bridge Books educational and project requirements.
2. The Book-Length Project Playbook v0.5, available at
   `C:\data\rick\projects\book_project_playbook\book-length-project-playbook-v0.5.md`,
   for reusable authoring, validation, and publication conventions.

Project-specific decisions take precedence over the playbook; the charter takes
precedence for Bridge Books pedagogy.

## Production decisions

- Canonical manuscript and workbook sources are Markdown.
- PDF artifacts are generated by Pandoc and LaTeX into `output/` and are never
  canonical source.
- The main book and the solutions workbook build separately.
- Python build helpers, when needed, use `uv`; TypeScript examples use the
  pinned Node/pnpm toolchain in this directory.
- Substantive examples, exercises, and solutions must be executable or
  type-checkable where practical. Snippets in the manuscript should be sourced
  from those checked files rather than maintained independently.
- The initial runtime baseline is Node 24.x and TypeScript 5.9.x under strict
  compiler settings. Exact installed dependency versions are recorded in
  `pnpm-lock.yaml`.

## Deliberate adaptations for a multi-language bridge

The reusable playbook assumes a largely Python-centric validation layer. This
book adds `package.json`, `pnpm-lock.yaml`, TypeScript compiler configuration,
and Node test execution. Fast checks must validate both the manuscript-facing
repository and executable TypeScript examples. A normal manuscript build must
not rewrite source Markdown, lockfiles, or curated assets.
