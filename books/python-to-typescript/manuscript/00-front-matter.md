## About this guide

This concise, practice-driven bridge is for experienced Python programmers who
want to write strict TypeScript for general Node.js libraries and command-line
tools. It focuses on the semantic and workflow differences that create costly
mistakes: types versus runtime values, data validation, absence, structural
typing, modules, and asynchronous I/O.

The guide does not teach a browser framework, database, or deployment platform.
Its examples use Node 24 and TypeScript 5.9 under strict compiler settings.
